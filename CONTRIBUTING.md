## Ошибки и предложения

Создайте Issue: укажите версию, платформу, шаги воспроизведения и ожидаемый результат. Для предложения новой функции опишите задачу и желаемое поведение.

## Изменения через Pull Request

Создайте форк и отдельную ветку, внесите изменения и откройте PR в основной репозиторий. В описании укажите связанную Issue, назначение изменения и выполненные проверки.

Прямые push, изменение веток и тегов, слияние PR и выпуск релизов в основном репозитории выполняет только владелец `rkislov`. Права записи сторонним участникам не предоставляются. Workflow внешних PR запускаются после одобрения владельца.

Указание владельца не изменяет лицензии, уведомления об авторских правах и авторство сторонних компонентов.
