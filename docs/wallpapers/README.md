# Кладовка — Wallpaper Pack (Banksy-inspired street art)

Оригинальные фоны в эстетике стрит-арта / трафаретного граффити (в духе Banksy),
тема объектного хранилища «Кладовка». Это **не** копии существующих работ.

## Темы

| Файл-префикс | Мотив |
|--------------|--------|
| `locker` | ребёнок ставит ящик в шкаф-кладовку |
| `rat` | крыса с кабелем и ящиками |
| `balloon` | девочка с облаком-бакетом |
| `door` | дверь в полки с янтарным светом |
| `ui-wall` | тёмная бетонная стена для UI |

## Разрешения

| Каталог | Размер | Назначение |
|---------|--------|------------|
| `1080p/` | 1920×1080 | Full HD |
| `1440p/` | 2560×1440 | QHD |
| `4k/` | 3840×2160 | 4K UHD |
| `5k-retina/` | 5120×2880 | 5K iMac Retina |
| `macbook-retina/` | 2880×1800, 3024×1964, 3456×2234 | MacBook Pro Retina |
| `masters/` | 1280×720 | исходные мастер-кадры |

На macOS: System Settings → Wallpaper → Add Folder… → выберите нужный каталог.
