## Исходники и обновление

[content.json](content.json) содержит текст слайдов 2–23 и ссылки на источники. [build.mjs](build.mjs) экспортирует функции `addCover` и `addBatch` для вызова внутри Artifact Session с привязанной презентацией. Это callback для среды авторинга, а не автономная программа Node.js.

Создайте пустую презентацию 1280×720, передайте корень checkout как `input.root`. Вызовите `addCover` один раз, затем `addBatch` с `input.slides` по 4–5 записей из JSON. Не повторяйте пакет в уже заполненной презентации: он добавляет слайды. После редактирования отрендерите и просмотрите все слайды.
